# Native port status

The project starts from the console-tested Smash 64 3DS port, v1.0.1. The **complete Remix +EXTRA mod is not playable on the 3DS yet**. This repository is the separate development project; the original game's working release is unchanged.

The scalable porting path is to assemble the pinned N64 mod, extract its final per-fighter tables and motion scripts, then generate native 3DS data from those compiled results. The mod's patch macros may modify many fighters at once, and this extraction preserves their final values without reimplementing each macro invocation. MIPS routines and engine hooks cannot execute in the ARM11 process: the callback audit groups all uses of each target so a shared behavior is translated into native C once and bound everywhere it is used. Generated data and a bound function pointer are prerequisites for gameplay testing, not evidence that a character or stage is complete.

Work on the full mod should advance shared table importers, callback families, engine hooks, and asset semantics before adding more hand-integrated fighters to the temporary selector. Each shared change should be checked against every affected fighter in the pinned reference and then exercised in an emulator; catalog expansion alone is not release progress.

The special-entry importer now reads all six final `Character.table_patch_start` dispatch tables, groups shared MIPS targets by instruction shape, and emits ARM handlers only for routines whose status change, animation call, motion-flag writes, and return path are fully decoded. The pinned build has 257 changed slots, 181 unique routines, and 100 unresolved instruction-shape groups; 11 routines pass the current strict decoder. An unresolved entry blocks its fighter automatically. The private auto roster has 30 structural fighters, including Lucas and N Lucas via one checked shared aerial callback. Ness-derived variants now load the original Ness effect model alongside their own fighter files, since the common PK Thunder effects use fixed offsets that are invalid in Lucas's model. Lucas and N Lucas reached stereo results scenes at frames 5124 and 5112 without the earlier stale-token error. Full moveset and mode behavior remains unverified; the development CIA is not a full-mod release.

## Remaining native integration

1. **Fighters and engine patches.** The original C engine has the vanilla fighter tables. Remix supplies an expanded registry, action tables, callbacks, items, AI, and engine hooks in N64 MIPS assembly. These must be translated or mapped to native C implementations, with correct ARM structures and pointers. The inventory records 404 base Remix assembly files and 1,969 patch calls; +EXTRA adds 19 fighter definitions, including variants, and additional code.
   The current audit finds two fighter dependency closures containing unresolved relocation records and one fighter with two script decoding failures. Structural import for other fighters does not establish correct moves, specials, or menu behavior.
2. **Movesets and relocation semantics.** The current conversion flags two internal relocation targets in Peach's turnip graphics. The importer now traces each invalid target through every possible aligned dependency-root layout. Both land inside file 161 when `PEACH_MAIN` (4974) is the root, but neither has an owner when `PEACH_TURNIP_INFO` (5143) or `PEACH_TURNIP_GFX` (5144) is the root. The two descriptors and the graphics payload are byte-identical in the pinned base Remix 2.0.1 ROM and final +EXTRA ROM, so +EXTRA did not introduce them. Their intended use remains unproven; a single plausible owner is not enough to rewrite the native pack. The 24 external cross-file pointers were converted to direct owner references only after reproducing the N64 allocator's order and checking that every load-root context agreed; the six raw end-image headers were cleared only after identifying their exact `G_ENDDL` shape. The full pack remains gated until the two Peach targets are understood and native use is tested.
3. **Menus, stages, music selection and saves.** Integrate expanded selection menus, expose the imported stages, translate expansion-owned setup routines and hazards, implement alternate music selection, and port the mod's save data. Preserve original and mod credits. The reference builder includes the entire base mod; it is not limited to +EXTRA's character folders.
4. **Gameplay validation.** Exercise actual new-character moves, projectiles, collisions, KO/results, single-player transitions, and credits in the 3DS emulator. Then measure memory use and frame times on New 3DS hardware, including four fighters and stereo. The original port's performance does not establish Remix performance.

The default release commands stop until that integration is ready. The separate fighter development packager does not change that status. No complete Remix CIA or release tag has been published.
